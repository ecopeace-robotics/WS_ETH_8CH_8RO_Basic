Detailed Description

High-level relay control API built on top of exio.h. Maps relay IDs (RELAY_1..RELAY_8) to TCA9554 output bits.

enum relay_id_t

Relay channel identifiers mapped to TCA9554 output bits. RELAY_1 corresponds to bit 0 (EXIO1), RELAY_8 to bit 7 (EXIO8).
